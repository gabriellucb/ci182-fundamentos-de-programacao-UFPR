'''
11. Fazer um programa em Python para calcular e imprimir a soma dos números primos entre dois inteiros N e K positivos informados pelo usuário no início da execução do programa. 
'''

n = int (input ("Digite n: "))
k = int (input ("Digite k: "))

'''
Esse codigo considera um intervalo fechado. Caso queira considerar um intervalo aberto, o "for" seria escrito da seguinte maneira:
for i in range (n+1, k)
'''

soma_total = 0
for i in range (n, k + 1):
	if i <= 1:
		eh_primo = False
	else:
		eh_primo = True
		for j in range (2, i):
			if i % j  == 0:
				eh_primo = False
				break
	if eh_primo == True:
		soma_total = soma_total + i

print ("Soma total:", soma_total)
