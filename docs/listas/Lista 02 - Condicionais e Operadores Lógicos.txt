- Exercício 9
Você está desenvolvendo o software de monitoramento para uma estação de
tratamento de água. O sistema lê continuamente o nível de Cloro Residual (mg/L)
e verifica o estado de um Botão de Interrupção de Emergência.
O programa deve solicitar dois valores:
1. O nível de Cloro (número decimal).
2. O estado da interrupção: digite 1 para Ativado ou 0 para Desativado.
Regras de Operação:
• Se a interrupção estiver ‘Ativada’ (1), o sistema deve ignorar a leitura do
cloro e exibir: "Operação Suspensa: Sistema paralisado pelo operador".

• Se a interrupção NÃO estiver ativa, o programa deve avaliar o cloro:
o

Entre 0.2 e 2.0 (inclusive): Exibir "Monitoramento: Nível Ideal".

o

Fora desse intervalo: Exibir "Alerta: Nível de cloro fora dos padrões.
Verifique o dosador".

Dica: No python Bool(1) vira True e Bool(0) vira false. Utilize isso.
Exemplo de Execução:
Entrada:
Nível de Cloro: 1.0
Interrupção (1 = Ativado / 0 = Desativado): 1
Saída Esperada:
Operação Suspensa: Sistema paralisado pelo operador.

Nível de cloro: 1.8
Interrupção (1 = Ativado / 0 = Desativado): 0

Monitoramento: Nível Ideal.

- Exercício 10 (Desafio)
Você foi contratado para programar a lógica de segurança de um elevador
industrial. O elevador transporta materiais sensíveis e possui três sensores:
1. Peso (int): Carga atual em kg.
2. Porta (bool): 1 se estiver aberta, 0 se estiver fechada.
3. Botão de Emergência (bool): 1 se estiver pressionado, 0 caso não.
O sistema de hardware é antigo e, às vezes, os sensores enviam sinais
contraditórios. Você deve implementar as seguintes regras de decisão:
1. Prioridade Máxima (Emergência): Se o botão de emergência estiver ativo, o
elevador deve travar imediatamente.
2. Segurança de Cabine: O elevador nunca pode se mover com a porta
aberta. Se houver peso e a porta estiver aberta, o sistema deve impedir o
movimento e avisar o erro.
3. Sobrecarga Crítica: O limite técnico é de 1000kg. Se o peso exceder isso, o
elevador não deve se mover.
Contradição de Sensor: Se o sensor de peso marcar zero ou menos, mas a porta
estiver fechada, o sistema deve entender que o sensor de peso falhou (pois o
elevador nunca fica vazio e fechado ao mesmo tempo no protocolo da fábrica).
Crie um programa que receba peso, porta e emergencia. O programa deve exibir
apenas uma das seguintes mensagens, respeitando a hierarquia:
• "STATUS: BLOQUEIO TOTAL": Se a emergência estiver ativa.

• "STATUS: ERRO DE PORTA": Se a porta estiver aberta (e não for emergência).

• "STATUS: SOBRECARGA": Se o peso for maior que 1000 (e a porta estiver
fechada e sem emergência).

• "STATUS: SENSOR DE PESO AVARIADO": Se o peso for <= 0 com a porta
fechada (e sem emergência).

• "STATUS: LIBERADO PARA SUBIR": Se o peso for entre 1 e 1000, porta
fechada e sem emergência.
