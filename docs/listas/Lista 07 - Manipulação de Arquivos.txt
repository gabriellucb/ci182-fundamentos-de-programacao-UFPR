Lista 07 – Manipulação de Arquivos
Revisão
•
•

Abertura de Arquivos: Usamos a função open("nome_do_arquivo.txt", "modo").
Modos de Operação:
"r" (Read): Lê o arquivo (o arquivo precisa existir).
"w" (Write): Escreve no arquivo. Se o arquivo já existir, ele apaga tudo e recria do zero!
"a" (Append): Adiciona conteúdo ao final do arquivo sem apagar o que já existe.

•

arq.read(): Lê o arquivo inteiro como uma única String.

•

arq.read().splitlines(): Lê o arquivo e devolve uma Lista, onde cada elemento é uma
linha do arquivo.

•

Escrita: Usamos arq.write("texto"). Lembre-se que o .write() não pula linha
automaticamente, você deve adicionar \n no final da string.
Fechamento: Nunca esqueça de usar arq.close() após terminar de usar o arquivo
para salvar as alterações e liberar a memória!

- Desafio
Em jogos, o inventário do personagem é frequentemente atualizado e consultado.
Vamos simular isso utilizando os três modos de ficheiro ("w", "a", "r").
Inicie o inventário. Abra um arquivo chamado mochila.txt em modo de escrita ("w")
e grave dois itens iniciais (um por linha), Ex: "Mapa" e "Moedas". Feche o arquivo.
Crie um laço perguntando se o usuário quer adicionar um item (S/N). Se sim (‘S’),
peça para digitar o nome. Abra o arquivo em modo de adição ("a"), grave este novo
item com uma quebra de linha (\n) e feche o arquivo.
Caso o usuário digite ‘N’, mostre o inventário completo. Abra o arquivo em modo
de leitura ("r"), extraia as linhas usando .read().splitlines() e imprima a lista
atualizada. Utilize também a função len() para informar quantos itens o inventário
tem no total.
Exemplo de execução:
Entrada:
Adicionar item (S/N)? S
Qual o nome do item? Câmera
Adicionar item (S/N)? N
Saída Esperada:
Item adicionado!
Inventário Atualizado: [‘Mapa’, ‘Moedas’, ‘Câmera’]
O inventário tem o total de 3 itens.
