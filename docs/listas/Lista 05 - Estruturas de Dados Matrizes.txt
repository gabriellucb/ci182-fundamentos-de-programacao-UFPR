Lista 04 - Estruturas de Dados: Matrizes
Revisão
• Criação: Uma matriz é representada por listas aninhadas. Ex: m = [[1, 2], [3, 4]].
• Acesso por Índices: O acesso é feito usando dois pares de colchetes, onde o
primeiro indica a linha e o segundo a coluna. Exemplo: matriz[linha][coluna].
• Modificação: Pode substituir um dado diretamente com os índices. Ex: m[0][1] = 10.
• len(matriz): retorna a quantidade de linhas. Para obter a quantidade de colunas de
uma linha específica (ex: linha 0), usamos len(matriz[0]).
• Varredura (Loops): Para percorrer todos os elementos de uma matriz, geralmente
utilizamos laços de repetição aninhados (um for dentro de outro).

- Exercício 14

encontrar a matriz resultante e, em seguida, verifique se essa resultante é a
Identidade. Imprima se as matrizes são ou não inversas
Exemplo de execução:

Matriz A:
Valor [0][0]: 4
Valor [0][1]: 7
Valor [1][0]: 2
Valor [1][1]: 6

Valor [0][1]: -0.7
Valor [1][0]:-0.2
Valor [1][1]: 0.4
Saída Esperada:
As matrizes são inversas!

- Desafio
Faça um programa que leia uma matriz 3x3 contendo os caracteres 'X', 'O' e ' '
(espaço vazio), representando o estado atual de um jogo da velha. O algoritmo
deve analisar as linhas, as colunas e as duas diagonais do tabuleiro para sugerir a
próxima jogada do jogador 'X'. A lógica da sugestão deve seguir uma prioridade:
1. Se o 'X' puder ganhar o jogo nesta rodada (tiver dois 'X' e um vazio na mesma
reta), sugira essa posição.
2. Caso não possa ganhar agora, mas o 'O' estiver prestes a ganhar (dois 'O' e um
vazio na mesma reta), sugira essa posição para bloquear a derrota.
3. Caso nenhuma das anteriores seja verdade, sugira qualquer posição vazia.

Exemplo de execução:
Entrada:
Tabuleiro:
Valor [0][0]: X
Valor [0][1]: O
Valor [0][2]: “”
Valor [1][0]: “”
Valor [1][1]: O
Valor [1][2]: “”
Valor [2][0]: X
Valor [2][1]: “”
Valor [2][2]: “”
Saída Esperada:
Jogada sugerida: [1][0]
