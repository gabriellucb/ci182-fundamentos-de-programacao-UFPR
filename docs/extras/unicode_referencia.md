## Como usar no VSCode

- **Linux**: `Ctrl+Shift+U`, digita o código hex (ex: `2192`), Enter
- **Mac**: segura `Option` e digita o caractere no teclado especial
- **Windows**: `Win+.` abre o painel de emoji/caracteres especiais
- **Qualquer sistema**: copie daqui diretamente

---

## Como usar no Python

```python
# Strings aceitam unicode normalmente
seta = "→"
caixa = "┌─┐"

# Ou pelo código do ponto Unicode, com chr()
print(chr(0x2192))  # →
print(chr(0x250C))  # ┌
```
