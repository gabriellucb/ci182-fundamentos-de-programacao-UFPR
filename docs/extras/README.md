# Extras

Material de apoio que não é aula, mas ajuda enquanto você estuda ou revisa.

- [`glossario.md`](glossario.md): termos técnicos explicados sem definição de livro, na ordem em que aparecem no curso.
- [`faq.md`](faq.md): dúvidas que aparecem com frequência, com explicação direta.
- [`referencia_rapida.md`](referencia_rapida.md): consulta rápida de sintaxe, métodos e padrões, para quando você já entende o conceito e só precisa lembrar como escreve.
- [`unicode_referencia.md`](unicode_referencia.md): caracteres especiais (setas, box drawing, símbolos) para copiar e colar em exemplos e diagramas de texto.
